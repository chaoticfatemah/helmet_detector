# 🪖 Helmet Detection System

A real-time Computer Vision system using **YOLOv8** and **OpenCV** to detect whether individuals are wearing safety helmets.

---

## 🚀 Features
- **Real-Time Detection**: Processes live webcam feed for helmet monitoring.
- **YOLOv8 Powered**: Lightweight and fast detection model.
- **OpenCV Integration**: Smooth frame-by-frame rendering and output display.
